# 07: 住宿备份与整体恢复迁移

**What to build:** 用户能导出住宿备份，预览并确认或取消恢复旧版及新版有效备份；恢复结果同步呈现在行程与路线中。

**Blocked by:** 04

Status: ready-for-agent

- [ ] 提供不依赖尚未迁移管理页面的可访问备份入口，React 界面使用共享住宿状态；导出保持既有版本和数据格式兼容。
- [ ] 导入在运行时校验版本、字段、坐标和晚次引用完整性，兼容旧有效备份，不以 TypeScript 静态类型代替校验。
- [ ] 导入展示内容预览和整份替换说明，取消不写入，明确确认后整体恢复而非自动合并。
- [ ] 无效文件、悬空引用和存储写入失败不破坏当前数据，并显示可理解反馈。
- [ ] 恢复后住宿详情、统计、端点及相关路线同步更新，刷新保留；恢复之前的延迟响应不得恢复过期估算。
- [ ] 通过页面操作、下载文件和持久化契约验证导出导入往返、旧备份、预览取消、无效拒绝、写入失败与恢复路线；不以旧全局业务对象驱动测试。
- [ ] 沿用现有备份浏览器测试场景，相关回归、严格类型检查与生产构建通过。
