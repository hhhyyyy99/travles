# 03: 高德自动加载与驾车路线迁移

**What to build:** 用户无需输入凭据即可使用已配置高德地图查看每日与全程驾车路线，加载失败时能重试或继续查看参考地图。

**Blocked by:** 02

Status: ready-for-agent

- [ ] 封装高德 SDK 的类型及服务边界，复用当前本地配置能力并给出无真实值示例，说明开发及生产配置方式；不提交真实配置。
- [ ] 有配置时自动加载，失败使用同一配置重试，不将访客导向凭据填写；缺少配置或服务不可用时保留参考地图与行程。
- [ ] 每日与全程路线、距离、时长及交通状态保留既有语义，缺失数据不编造结果，明确经纬度顺序及 WGS-84/GCJ-02 转换边界。
- [ ] 查询状态由显式模块与 React 状态联动；过期响应不覆盖最新日期或路线，SDK 必需全局入口之外不新增全局业务耦合。
- [ ] 地图、计时器、订阅和异步回调具有失效与清理机制，重复挂载和热更新不会累积实例或重复查询。
- [ ] 采用现有可控 provider fixture 验证自动加载、重试、失败、延迟及乱序，夹具仅替代外部服务；保留路线工具纯逻辑测试。
- [ ] 已迁移行为回归、严格类型检查及生产构建通过，生产预览验证地图资源及配置接入路径。
