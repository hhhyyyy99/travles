# 08: 打印当前行程与住宿迁移

**What to build:** 用户能够打印或另存 PDF，获得包含当前住宿名称、地址、备注及有效路线信息的完整行程。

**Blocked by:** 04

Status: ready-for-agent

- [ ] 打印内容由 React 和同一权威住宿状态派生，支持默认住宿及自定义多晚安排，不维护独立住宿数据副本。
- [ ] 保留七天行程及原有打印内容，完整呈现住宿名称、地址和备注；未更新路线不显示旧估算为当前结果。
- [ ] 沿用浏览器打印与另存 PDF，不引入独立生成服务；应用样式使用 Tailwind，必要的打印分页及全局规则可保留。
- [ ] 检查长名称、长地址、长备注及 A4 分页，不截断关键信息，不打印无关编辑控件。
- [ ] 打印结束或取消后交互页面和折叠状态恢复，反复打印不累积事件监听。
- [ ] 迁移现有打印浏览器测试并验证当前住宿、失效估算和长文本，记录视觉检查结果；相关回归、严格类型检查及构建通过。
