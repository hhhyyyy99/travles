# 02: 每日行程与参考地图迁移

**What to build:** 用户能够查看完整七天行程、切换每日详情与对应参考地图，并查看全程路线和住宿摘要。

**Blocked by:** 01

Status: ready-for-agent

- [ ] 保留七天六晚行程、文案、景点顺序、出发准备、导航锚点和原有视觉层次；不重排旅行计划。
- [ ] 日期选择、每日详情、默认住宿摘要和全程查看由 React 状态驱动，应用布局使用 Tailwind，行程及路线数据具有明确 TypeScript 类型。
- [ ] Leaflet 通过有类型的适配边界管理独立地图容器，日期切换联动标记和参考路线；底图失败时仍显示可用的行程与参考信息。
- [ ] 地图实例和事件随挂载清理，开发重复挂载及热更新不产生重复地图或监听器。
- [ ] 预置路线、图标、地图样式及相关资源在开发与生产预览中均能加载。
- [ ] 浏览器验收每日切换、全程查看和底图失败；核对桌面、手机布局及可访问名称，相关回归、类型检查和构建通过。
