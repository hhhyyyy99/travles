# 06: 住宿基地管理与默认恢复迁移

**What to build:** 用户能够集中编辑与清理住宿基地，恢复单晚默认住宿，并保持所有相关晚次、摘要和路线一致。

**Blocked by:** 04

Status: ready-for-agent

- [ ] React 管理界面区分使用中与备选基地，支持修改名称、位置、类型、地址及备注，沿用共享业务状态和 Tailwind 样式。
- [ ] 修改共用基地后关联晚次、摘要、地图及相关路线同步更新；位置变化使旧估算失效，失败及乱序规则与手动添加一致。
- [ ] 允许删除未使用的自定义基地；使用中基地必须先替换住宿，默认基地保持不可编辑删除的既有保护。
- [ ] 支持单晚恢复默认，不误改其他晚次；恢复后的端点、统计和路线状态正确。
- [ ] 操作成功后刷新保留；写入失败保留原有效安排并明确提示；键盘焦点和手机操作保持可用。
- [ ] 以页面流程迁移现有管理测试，覆盖共用基地编辑、删除保护、备选删除、默认保护和单晚恢复；相关回归、类型检查与构建通过。
