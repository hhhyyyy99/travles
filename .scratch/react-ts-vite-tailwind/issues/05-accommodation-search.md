# 05: 住宿搜索与重复提醒迁移

**What to build:** 用户能够搜索并确认住宿位置，处理重复基地提醒；搜索不可用时可保留草稿转为手动选点。

**Blocked by:** 04

Status: ready-for-agent

- [ ] 使用 React 与 TypeScript 实现查询、结果选择、位置确认及表单回填，沿用共享住宿创建流程，选中未确认结果不能直接持久化。
- [ ] 搜索结果在服务边界完成坐标归一化；酒店与住宿区域沿用现有模型，不编造缺失位置。
- [ ] 同名且邻近的候选提示重复，用户能复用现有基地或明确继续新建，不强制合并。
- [ ] 空结果、服务不可用和查询失败反馈准确；失败保留查询与草稿，手动选点仍可继续保存并应用。
- [ ] 快速修改搜索或关闭界面后，过期结果不覆盖当前查询及草稿；保留键盘操作、焦点行为和移动布局。
- [ ] 迁移现有搜索及重复判断行为测试和纯逻辑测试，通过外部 provider 夹具覆盖确认前不保存、复用、继续创建及失败回退；相关回归、类型检查与构建通过。
