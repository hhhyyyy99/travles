# 02: 模型 ID 升级为可过滤 combobox

**What to build:** 用户在 AI 接入设置页点「获取模型列表」成功后，模型 ID 字段从 datalist 联想升级为可关键字过滤的下拉浮层：列表项可直接点选、选中后回填输入框且仍可继续编辑；列表里没有的模型 ID（网关自定义路由名）仍可自由输入并保存；获取列表失败时给出明确错误且不阻塞手填。获取模型列表继续走现有两个接口（未保存 → 表单探测式获取；已保存 → 按已存密钥获取），无后端改动。

**Blocked by:** None (can start immediately)。

**Status:** done

- [x] 获取模型列表成功且非空时，模型 ID 字段出现下拉浮层，列表项点选即回填输入框
- [x] 浮层支持按关键字本地过滤（前端过滤已拉回的列表，不新增后端接口）
- [x] 选中后输入框保留可编辑状态；关闭浮层后可继续手改（如改版本号后缀）
- [x] 输入列表之外的模型 ID 可正常保存，手填能力不受下拉影响
- [x] 获取列表失败或返回空时展示明确提示，手填流程不受影响

- [x] 浏览器套件新增 AI 设置页测试：获取列表 → 下拉出现 → 点选回填 → 过滤生效 → 手填列表外 ID 可保存
