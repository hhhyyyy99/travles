# 03: 集中管理基地与恢复默认住宿

**What to build:** 用户集中管理使用中和备选基地，修改后同步更新行程；可安全删除自定义基地，并将任一晚恢复为原始默认住宿。

**Blocked by:** 01：手动添加住宿基地并用于行程

Status: ready-for-agent

- [ ] 提供住宿基地管理入口，区分正在使用和未使用的备选，展示关联住宿晚次。
- [ ] 编辑自定义基地的名称、位置、类型、地址和备注后，刷新仍保留且所有关联晚次、地图和住宿摘要一致更新。
- [ ] 位置变化重算所有受影响路段，保留路线失败提示与异步响应保护；文案修改不导致不相关路线被改变。
- [ ] 未使用的自定义基地可直接删除；正在使用的基地必须先替换所有关联晚次，不能产生悬空住宿引用。
- [ ] 每晚可恢复原有默认住宿，恢复后地图、计数、相关路线及本地保存一致。
- [ ] 默认住宿保留为可选项且不可删除，不允许通过管理操作破坏原计划的恢复能力。
- [ ] 浏览器流程验证多晚共用基地编辑、删除保护、替换后删除、恢复默认及刷新恢复，包含路线失败情形。
- [ ] 管理、编辑和恢复操作在移动屏幕及键盘操作下可完成。
