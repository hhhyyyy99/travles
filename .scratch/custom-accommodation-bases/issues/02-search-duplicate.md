**What to build:** 用户搜索住宿地点并确认位置后添加、保存和用于行程；搜索不可用时仍可手动选点，遇到疑似重复基地时可以复用已有地点或继续新增。

**Blocked by:** 01：手动添加住宿基地并用于行程

Status: resolved

- [x] 添加流程支持地点搜索、结果选择及地图位置确认，确认后使用与手动添加相同的保存和行程关联行为。
- [x] 搜索不可用、缺少配置、网络失败或无结果时显示明确反馈，并保持手动选点可用，不丢失已填写信息。
- [x] 名称相同且位置接近时提示可能重复，可选择已有基地，也可继续添加，不强制合并同址的不同酒店。

- [x] 搜索、结果确认和重复提醒在移动屏幕及键盘操作下可完成。

## Answer

已在 `accommodation-search.js` 接入高德 `PlaceSearch`，搜索结果必须点击确认后才会预填已有住宿编辑器；结果坐标从高德 GCJ-02 转换为住宿模型使用的 WGS-84 后再进入 ticket 01 的保存和分配流程。未连接高德、插件不可用、无结果或网络失败时，搜索文本和现有编辑草稿保留，并回退到地图选点。

名称相同且 1.5 km 内的基地会显示疑似重复提醒，用户可以选择已有基地，也可以继续新增。新增脚本和样式已接入主页面，并为 PlaceSearch 加载插件。
