# 02: 搜索地点添加基地与重复提醒

**What to build:** 用户搜索住宿地点并确认位置后添加、保存和用于行程；搜索不可用时仍可手动选点，遇到疑似重复基地时可以复用已有地点或继续新增。

**Blocked by:** 01：手动添加住宿基地并用于行程

Status: ready-for-agent

- [ ] 添加流程支持地点搜索、结果选择及地图位置确认，确认后使用与手动添加相同的保存和行程关联行为。
- [ ] 搜索不可用、缺少配置、网络失败或无结果时显示明确反馈，并保持手动选点可用，不丢失已填写信息。
- [ ] 名称相同且位置接近时提示可能重复，可选择已有基地，也可继续添加，不强制合并同址的不同酒店。
- [ ] 搜索结果须经用户确认，不因仅输入名称就保存无坐标基地。
- [ ] 新增或复用后可分配住宿晚次，并在刷新后保留及参与相关路线更新。
- [ ] 浏览器行为测试覆盖搜索成功、无结果、服务失败、复用重复项及坚持新增；外部服务响应可控，不依赖真实服务在线。
- [ ] 搜索、结果确认和重复提醒在移动屏幕及键盘操作下可完成。
