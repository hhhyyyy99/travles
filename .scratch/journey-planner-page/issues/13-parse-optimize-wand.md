# 13: 智能解析、路线优化、天级魔法棒

**What to build:** 三个 AI 增强能力：① 输入框旁"智能解析"——粘贴一段攻略长文本，AI 解析为结构化行程项供确认后写入；② "路线优化"——AI 对现有行程做全局优化建议（走法、顺序、节奏），确认后应用；③ 列表/画布天签上的魔法棒——只优化指定的一天。三者都走"建议 → 确认 → TripPatch 应用"路径，不静默改行程。

- [ ] 魔法棒只重排目标天，其余天不变
