# 05: 地图面板与画布联动

**What to build:** 右栏地图成为行程的真实投影：按日绘制约色的驾车路线 polyline（每日一色、带行车方向刻度），每日路线悬浮日里程标签（如"10.05 周一 185km"，颜色与画布天签一致），POI 按当日顺序显示序号标记（含碰撞隐藏）。点击画布卡片，地图聚焦该 POI 并弹出详情卡（名称、评分、类型签、图片轮播、简介、收藏按钮、了解更多外链）；点击地图标记，画布滚动到对应日并高亮卡片。地图控件：全图总览、缩放 +/−、我的位置；右上"总览"下拉。

**Blocked by:** 04。

**Status:** ready-for-agent

- [ ] 打开行程即见完整多日彩色路线与里程标签，日色与画布一致
- [ ] 点击画布卡片 → 地图聚焦 POI + 详情卡；关闭详情卡回到全览
- [ ] 点击地图标记 → 画布滚动定位并高亮对应卡片
- [ ] 路线绘制复用现有 Leaflet 主链路与 AMap 适配层，不新起地图方案
