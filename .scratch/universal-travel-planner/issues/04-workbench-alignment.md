# 04: 工作台对齐 pitravel（AI 助手 / 横向画布 / 待计划抽屉）

来源：Epic #3 → GitHub Issue #7。
Part of #3

**What to build:** 对齐 pitravel.cn 的三栏工作台沉浸式规划体验：左栏 AI 助手、中栏横向日程画布/列表、右栏地图 + 底部待计划/推荐/收藏抽屉。

**Blocked by:** 01、02。

**Status:** ready-for-agent

## 详细要求

1. **左侧 AI 助手栏**：
   - 宽度拖拽调整与收起。
   - `思考完成` 展开/折叠推理过程。
   - 地理硬约束冲突校验与事实呈现（如长途跨城车程警告、连带调整分析）。
   - 澄清问题与选项 Chips 点击即回复。
   - 方案建议 Diff 卡片与确认/放弃机制。
2. **中间日程画布/列表**：
   - 「画布（横向排布按天卡片）」与「列表」切换，支持画布缩放（放大/缩小）。
   - 节点卡片按类型区分图标与色标（游玩、交通、餐饮、住宿、便签）。
   - 卡片间显示驾车路线里程与耗时（如 `33.8千米 34分钟`）。
   - 天级「一键优化路线」与卡片拖拽重排、添加地点。
3. **右侧地图 + 底部「待计划/推荐」抽屉**：
   - 地图高亮当日线路与标记，点击卡片聚焦 POI。
   - 底部高度可拖拽面板：支持「推荐」、「待计划（灵感愿望单）」、「收藏」。
   - 支持按地区筛选，支持在地图上显隐待规划标记。
   - 待计划地点支持一键加入某一天或拖入画布。

## 验收标准

- [ ] AI 栏可拖拽调宽/收起；思考过程可折叠；Chips 点击即回复；提案以 Diff 卡片确认/放弃。
- [ ] 画布/列表可切换；画布可缩放；卡片按类型着色带徽标；卡片间显示里程与耗时。
- [ ] 天级一键优化与卡片拖拽重排/添加地点可用。
- [ ] 地图随当日联动、点击卡片聚焦 POI；底部抽屉可拖高，含推荐/待计划/收藏，支持地区筛选与标记显隐、一键排期。
- [ ] 提供 Before/After 视觉证据（同一场景、视口、主题）。
- [ ] `pnpm typecheck` 与 `pnpm test` 全绿。
