# 03: 首页重构对齐 pitravel 双 Tab 创建与行程卡片流

来源：Epic #3 → GitHub Issue #6。
Part of #3

**What to build:** 重构前端首页（TripListPage），完整复现 pitravel.cn 的视觉美学与创建体验：Hero 双 Tab 创建面板 + 行程卡片库（我的计划 / 我的收藏）。

**Blocked by:** 01、02。

**Status:** ready-for-agent

## 详细要求

1. **Hero 创建面板**：
   - 双 Tab 切换：
     - Tab 1「AI创建计划」：输入目的地与自由偏好（如「成都5天美食慢节奏」），提供常用快捷标签，一键生成。
     - Tab 2「解析链接」：输入小红书/携程/公众号攻略链接，或直接粘贴攻略长文本，一键启动后端 Mastra 解析管道并展示进度。
   - 辅助入口：「想从空白开始？手动创建计划」弹窗。
2. **行程卡片库**：
   - 切换分栏：「我的计划」与「我的收藏」。
   - 卡片呈现：高质感风景封面（根据目的地自动匹配精选库，并支持自定义更换）、行程天数与地点统计、状态徽章（已置顶、进行中、已结束）、最后编辑时间。
   - 操作菜单：置顶/取消置顶、重命名、复制行程、更换封面、删除行程。

## 验收标准

- [ ] 首页 Hero 区可切换「AI创建计划」/「解析链接」双 Tab；解析链接可输入 URL 或粘贴长文本并经后端管道解析。
- [ ] 「手动创建计划」弹窗可创建空白行程。
- [ ] 卡片库可分「我的计划」/「我的收藏」；卡片显示封面、天数与地点统计、状态徽章、最后编辑时间。
- [ ] 卡片操作支持置顶/取消置顶、重命名、复制、更换封面、删除。
- [ ] 提供 Before/After 视觉证据（同一场景、视口、主题）。
- [ ] `pnpm typecheck` 与 `pnpm test` 全绿。
